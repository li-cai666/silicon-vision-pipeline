事情是这样的。昨天我在 GitHub 上刷到一个仓库，叫 HowToLiveBetter ，高性价比人生指南。我寻思这名字起得挺狂啊，点进去一看， 4.5 万 star 。更离谱的是，这仓库 9 月 7 号才建，到今天刚好一个月——一个月，4.5 万 star，332 次提交，昨天还在更新。

仓库首页：45.8k star，9 月 7 日建库，一个月登顶

说实话我第一反应是，又是一个鸡汤合集吧。但往下翻了十分钟，我把这个判断收回去了。这玩意不是鸡汤，这是一本用 循证医学写法 写的「人生说明书」。全书 667 条 ，每条都长一个样：成本多少，一句说人话的解释，收益是什么，证据等级，原始出处。出处只认两种——期刊论文和官方文件，光文献链接就挂了 1675 条。

全书 34 章目录：从「不要早死」到「出国技能」，把普通人一生的坑都排了一遍

01
给你举几个例子
/ 三条有代表性的条目

第 9 条，把家里的食盐换成 低钠盐 。成本，一袋比普通盐贵几块钱。收益，一项在中国农村做的随机对照试验， 20995 人 、跟踪快 5 年，用低钠盐那组五年内死亡概率低约 12%，中风低约 14%。发在 NEJM，证据等级 A，最高那档。

仓库原文：成本 / 解释 / 收益 / 证据等级 / 出处，五段式固定格式

几块钱一袋的盐，换 12% 的死亡风险下降 。我看到这条的时候真愣了一下，这就是标题里说的性价比。

再看第 19 章， 不要签「个人原因主动辞职」 。公司让你签这个字的时候往往笑眯眯的，但签下去，经济补偿和失业保险金通常一起落空——因为法律上该给补偿的情形里，不包括你自己主动走。作者特意补了一句：不必当天签，冷静一晚再说。

还有一整章叫「 反面清单 」，专收那些看起来性价比高、其实不高的东西：为长寿吃复合维生素，没用；没症状去做全身 PET-CT 套餐，没用还白挨辐射；指望氨糖治膝盖，没用。每条后面都挂着论文。

02
AI 与人协作的范本
/ 让我更感慨的地方

README 里明晃晃写着，本书在 Claude Code 协助下编写：AI 负责查文献、核对数字、维护交叉引用，选题、取舍和最终审定由人负责。更新全靠 GitHub issue 驱动，读者发现问题提 issue，作者核实了再改。还有个每周自动跑的脚本，专门检查那 1675 个文献链接有没有失效。

人定选题 → AI 查文献、核数字 → 人终审

这可能是我今年见过的， AI 和人协作最好的形态之一 。AI 干体力活，人下判断。

现在这个仓库已经有了英俄西葡越五种语言的翻译，有人给它做了打勾清单网站，有人做了微信小程序。全是陌生人自发干的。说真的，我很久没在一个开源项目上看到这种场面了——以前让我有类似感觉的都是改变行业的代码库，这次不是代码，是 667 条「怎么活得更好一点」的答案，被认认真真钉在了证据上。

信息不值钱， 被核实过的信息 才值钱

那 4.5 万个 star，投的其实是 1675 条一条一条核过的文献。

开头我说，我默默把家里的盐换了。是真的换了。低钠盐，超市就有，贵三块五。
